# 🚀 InternNova Homepage Redesign

A modern, responsive, and interactive redesign of the **InternNova homepage**, created as part of a Web Development Internship project.

The goal of this project is to improve the existing website's **UI/UX, visual hierarchy, responsiveness, navigation, and overall user experience** while maintaining a professional identity suitable for an internship and learning platform.

> **Note:** This is an independent redesign concept created for an internship project. It is not the official production website of InternNova.

---

## 🌟 Project Overview

The redesigned homepage provides students with a clear and engaging way to discover InternNova's internship opportunities, learning programs, workshops, and resources.

The interface uses a modern dark theme with gradient accents, interactive components, smooth animations, and responsive layouts.

## 🎨 Design Concept

The redesign follows a modern **EdTech and career-development platform** style.

### Color Palette

- **Dark Navy** — Main background
- **Purple** — Primary accent
- **Cyan** — Secondary accent
- **White** — Primary text
- **Light Blue/Grey** — Secondary text

The combination creates a technology-focused and professional appearance while maintaining strong readability and visual hierarchy.

## 🌐 Deployment

The project can be deployed using:

- GitHub Pages
- Vercel
- Netlify

### GitHub Pages

1. Upload the project to a GitHub repository.
2. Open the repository **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch.
6. Select `/ (root)`.
7. Save the configuration.
8. Wait for GitHub Pages to generate the live website URL.
